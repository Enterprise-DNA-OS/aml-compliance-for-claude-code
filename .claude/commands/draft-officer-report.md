# draft-officer-report

Draft the compliance officer's report to the governing body or senior managers.

Read fresh data. Never invent a customer, a check result, a date or command output. These records hold personal information and must stay inside the firm.

```bash
node scripts/aml.mjs draft-officer-report <firm> --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Counts only. Never name the customers behind a suspicious activity report. Nothing here runs a check, sends an email or lodges a report.
