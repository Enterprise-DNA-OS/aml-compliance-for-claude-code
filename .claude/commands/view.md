# view

Render the read-only dashboards: this week, the customer risk register and the programme.

Read fresh data. Never invent a customer, a check result, a date or command output. These records hold personal information and must stay inside the firm.

```bash
npm run view
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Files land in views/. Say which to open. Nothing here runs a check, sends an email or lodges a report.
