# weekly-review

Draft the Monday AML review from attention, reports and compliance.

Read fresh data. Never invent a customer, a check result, a date or command output. These records hold personal information and must stay inside the firm.

```bash
node scripts/aml.mjs weekly-review --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Read the draft back in five lines: overdue reports, matches, CDD gaps, programme dates, training. Nothing here runs a check, sends an email or lodges a report.
