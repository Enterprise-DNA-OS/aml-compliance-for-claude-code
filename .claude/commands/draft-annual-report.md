# draft-annual-report

Draft the working pack for the annual AML/CFT report to DIA or the AUSTRAC compliance report, with the counts.

Read fresh data. Never invent a customer, a check result, a date or command output. These records hold personal information and must stay inside the firm.

```bash
node scripts/aml.mjs draft-annual-report <firm> --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Read back the due date and the counts. Nothing submits from here. Nothing here runs a check, sends an email or lodges a report.
