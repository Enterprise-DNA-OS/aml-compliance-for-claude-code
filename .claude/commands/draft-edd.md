# draft-edd

Draft the letter asking a customer for identity, source of wealth or source of funds documents.

Read fresh data. Never invent a customer, a check result, a date or command output. These records hold personal information and must stay inside the firm.

```bash
node scripts/aml.mjs draft-edd <customer> --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Never add anything that hints at a concern or a report. Nothing here runs a check, sends an email or lodges a report.
