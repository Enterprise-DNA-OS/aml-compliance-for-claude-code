# programme

The AML programme calendar per firm: risk assessment, programme review, audit or independent evaluation, officer report, annual report.

Read fresh data. Never invent a customer, a check result, a date or command output. These records hold personal information and must stay inside the firm.

```bash
node scripts/aml.mjs programme --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Lead with anything past due, then the next 90 days. Nothing here runs a check, sends an email or lodges a report.
